# Drillships
Drillships is a Neoforge minecraft mod inspired by the game Volcanoids. This mod brings drillships similar to that of Volcanoids. These drillships can be piloted and bore through the world, they can collect resources and be upgraded.

## Features

### Drillships
Drillships are the main feature of the mod, they can be crafted, upgraded and modified.
Drillships come in three tiers: Basic, Standard and Hardened. Higher tiers are larger and support more wagons.
|Tier|Size (wxhxl)|Max Wagons| Inventory Capacity|
|--|--|--|--|
|Basic|3x3x7|3|100|
|Standard|5x5x10|5|150|
|Hardened|9x9x15|8|200|

By default drillships are powered by burnable items. The ship generates FE this way and has an internal buffer, this internal buffer can be accessed through plugs to input/output energy. 

### Tesla turrets
Install tesla turrets in your ship for self defense. There are two turrets available: Short and medium range. Both turrets deal low damage very quickly and pierces armor. These turrets use FE from the buffer.
You can only have one turret per wagon.

### Modules
Modules are appliances that can be embedded in the wall of your ship. 
- Crafting table module
- Furnace Module
- Inventory Access Module
- Energy IO Module
- Crafting & Inventory Access
- Door module

### Ore deposits
The mod generates large ore deposits that can be located using the drillship. The drillship supports a radar that can guide you to these deposits.
